# October 2026: The world today, as seen by just another Polish guy

A bilingual (EN/PL) scrolling reply to [“September 2026: The world today, as seen by one Polish guy”](https://tomwojcik.com/posts/2026-09-21/september-2026-the-world-today/): the same map and the same autumn, told through the measurable things that keep getting better in Poland.

- `index.html` – the built, self-contained page (served by GitHub Pages)
- `src/template.html` – all text, chart specs and map code
- `src/world.topo.json` – world map geometry
- `poland_positive_content_bank_merged.json` – the 191 evidence cards and their sources
- `build.py` – run `python3 build.py` after editing the template

Add `?lang=pl` or `?lang=en` to force a language, `?instant` to turn off animation.
